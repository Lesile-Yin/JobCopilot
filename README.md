## 📖 简介

在 BOSS 直聘求职时，你是否厌倦了：一个个点岗位、投到一堆根本不匹配的岗位？

**JobCopilot** 帮你把这套重复劳动自动化：

> 设定关键词 → 自动收集岗位 → **AI 按你的简历智能筛选** → 你勾选确认 → 自动**逐个**发起沟通、发送招呼语。

## ✨ 功能特性

- 🔍 **自动搜索收集**：按关键词、城市自动抓取岗位（无限滚动加载），数量自定义
- 🤖 **AI 智能筛选**：智谱 GLM-4-Flash 结合你的简历，自动判断岗位是否匹配并给出理由
- 🚫 **屏蔽关键词 / 最低薪资**：含屏蔽词或低于薪资期望的岗位自动跳过
- ✅ **审核确认机制**：投递前列出匹配岗位（含公司名、薪资、筛选理由、岗位链接），你勾选确认，绝不盲投
- 🎯 **精准投递**：只投勾选的岗位；投递前校验详情面板岗位名与目标一致，防止投错
- 💬 **默认招呼语**：固定话术「您好，我对贵司在招的「岗位名」岗位很感兴趣，方便详细沟通一下吗?」
- 📊 **实时日志面板**：进度、成功/失败一目了然，支持暂停 / 停止 / 重置
- 🛡️ **拟人化节奏**：随机延迟、逐个投递，自然防风控；已投去重不重复打扰
- 🔄 **一键热重载**：改代码后侧边栏点「重新加载」即可，无需重新导入

## 🚀 快速开始

### 1. 克隆仓库
```bash
git clone https://github.com/Lesile-Yin/JobCopilot.git
```
或直接 `Code → Download ZIP` 解压。

### 2. 加载扩展（Chrome / Edge 通用）
1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择项目文件夹（推荐用纯 ASCII 路径）
4. 点击扩展图标，打开侧边栏

### 3. 配置
| 配置项 | 说明 |
|--------|------|
| 智谱 API Key | 在 [open.bigmodel.cn](https://open.bigmodel.cn) 免费申请，用于 AI 岗位筛选（必填） |
| 简历文字 | 用于 AI 筛选岗位（必填） |
| 关键词 / 城市 | 岗位搜索条件 |
| 收集数量 | 每次抓取的岗位数 |
| 屏蔽关键词 | 含任一关键词即跳过（逗号分隔） |
| 最低薪资 | 低于该值（K/月）的岗位跳过 |

> AI 筛选使用智谱 GLM-4-Flash 模型，在 [智谱开放平台](https://open.bigmodel.cn) 注册即可免费申请 API Key。

### 4. 使用
**开始收集 + AI 筛选** → 在 **审核确认** 区勾选要投的岗位 → **投递选中** → 看着日志自动跑完。

## 🔄 工作流程

```
┌─────────┐   ┌──────────┐   ┌──────────┐   ┌──────────────────────────┐
│ 配置条件 │ → │ 收集岗位  │ → │ AI 筛选   │ → │ 人工审核勾选              │
└─────────┘   └──────────┘   └──────────┘   └──────────────────────────┘
                                                        │
                                                        ▼
              对每个选中岗位逐个闭环：
              打开详情校验岗位 → 立即沟通 → 进入聊天 → 发默认招呼语 → 下一个
```

## 🔄 热重载

改代码后 Chrome MV3 必须重载扩展才生效，但**无需重新导入**：

1. 侧边栏顶部 **「🔄 重新加载」** 按钮（推荐）
2. 快捷键 **Cmd+Shift+9**（`manifest.json` 已注册）
3. 全自动：`tools/watch-reload.mjs` 监听源码变化自动重载（需 Chrome 以 `--remote-debugging-port=9222` 启动）

## 🛠️ 技术栈

- **浏览器扩展**：Manifest V3，原生 JavaScript，无框架
- **AI 模型**：智谱 GLM-4-Flash（`open.bigmodel.cn`）做岗位筛选
- **架构**：侧边栏（持久页面）承载全部流程，绕开 Service Worker 生命周期被杀问题；Content Scripts 操作页面

## 📁 项目结构

```
├── manifest.json           # MV3 清单：权限 / 侧边栏 / 快捷键
├── src/
│   ├── background.js       # 极简：仅图标开侧边栏 + 快捷键热重载
│   ├── sidepanel.js        # 核心编排：收集→筛选→审核→投递（持久页面）
│   ├── sidepanel.html/css  # 侧边栏界面（配置 / 审核 / 日志）
│   ├── content-search.js   # 搜索页：抓取岗位 + 建立联系（防错投校验）
│   ├── content-chat.js     # 聊天页：发送招呼语 + 可视化高亮
│   └── selectors.js        # DOM 选择器与城市编码
├── icons/                  # 扩展图标
├── tools/                  # 开发工具（热重载 / Chrome 调试启动）
└── docs/                   # 投递流程图等文档
```
